# 栏目排序

各状态栏独立按会话更新时间选择新的在前或旧的在前。默认待归档旧的在前，
其他栏目新的在前。会话更新时间不是创建时间或进入状态的时间。
设置属于栏目，跨项目、搜索、本机和远程会话共用；空列也能设置。

偏好保存在既有数据库 settings 表的 column_sort:<状态>，字段与方向分开。
每次仅修改一个栏目，携带该栏目独立版本，旧编辑被拒绝并要求刷新。
HTTP /api/column-sort 和 MCP board_sort 使用同一保存操作。
排序保存不触发状态确认、清除新输入复核提示、同步标题或修改原生分区。

未来优先级属于会话元数据，随会话跨栏保留，需独立保存操作。
排序入口扩展为优先级优先、同优先级再按时间、最后按稳定会话身份。
时间方向只作用于时间比较。当前不加入未实现的优先级字段或选项。
