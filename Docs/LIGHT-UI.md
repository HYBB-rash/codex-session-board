# 轻量会话看板

本轮保持现有五列看板和六列兼容模式，统一信息层级、主题与交互。
不增加前端框架、字体服务、图标库或运行时 CDN。
独立浏览器跟随系统主题；MCP 页面先采用宿主初始主题，再响应宿主主题通知。
宿主安全边距写入 CSS 变量，不改变连接层、原生会话或历史补读方式。

## 卡片与布局

- 标题和卡片空白处打开原会话，底部“调整”打开现有状态与备注编辑器。
- 项目名称保留在卡片上，目录、工作目录和状态来源放入项目详情。
- 备注默认最多三行，实际溢出才提供“查看完整备注”，展开和编辑均保留完整内容。
- 阻塞原因、跟进输入、只读、归属异常、标题同步和保存等待提示始终保留。
- 短窗口的看板内容至少 280px，滚动容器按内容最小尺寸保留滚动条空间。
  内容层使用尺寸包含，避免卡片数量或展开备注反过来撑大最小高度。
  外层可纵向滚动，各列保持自己的滚动位置。
- 未变化的列保留卡片节点；变化的列恢复项目详情、备注展开状态和卡片操作焦点。
  原卡片消失时，焦点回到原列排序按钮。状态跳转按钮保持节点稳定。

列内容签名包含完整会话、项目资料、状态定义、所选主机、兼容模式、
保存和新建状态、未确认操作、空列读取状态，以及正在移动的来源占位。
不要只比较会话 ID 或版本：权限、项目资料和等待中的搜索结果也会改变界面。

## 健康与远程目录

“连接正常”要求列表读取完整、运行时已验证、所需原生分组已验证，
并且项目资料已读取、没有错误、缓存、未完成或等待刷新状态。
资料尚未确认时保留具体状态，不把未知显示为正常。

远程目录兼容参考为 `9160e4b` 的已提交字段，本分支不包含其后端实现。
支持活动、已归档、全部目录和历史缓存范围，按当前范围计数。
归档和历史缓存仍可打开，不能拖动、修改备注或再次归档。
目标端项目可以浏览；只有明确支持新建的项目才进入新建列表。
切换主机和历史范围只改变显示，不发送连接或刷新请求。
主动“刷新”和“连接”继续使用原有明确入口。

最终集成前须冻结远程目录最终来源头，重新核对字段、权限、计数与健康提示，
并执行组合门禁。不能把本次兼容 fixture 当作远程后端完整验收。

## 离线桥接构建

可读入口为 `assets/app-bridge-entry.mjs`。
`assets/app-bridge.package.json` 与 `assets/app-bridge.package-lock.json`
固定原有 SDK 2.0.4 和 esbuild 0.28.2，保留依赖来源与完整性校验。
锁文件的每个包占一行，避免压缩为单行或引入与改动无关的格式差异。

```sh
node scripts/build-app-bridge.mjs
node scripts/build-app-bridge.mjs --check --offline
```

构建在临时目录执行 `npm ci --ignore-scripts`，产出离线 IIFE 与许可证文件，
结束时删除临时目录。首次缺少 npm 缓存时省略 `--offline`。
不要手改生成包，也不要在 Rust 中通过替换压缩字符串增加路由。
MCP 资源直接内嵌生成包，保留九条操作和结构化、文本及错误结果处理。

## 验证与交付

`tests/ui_layout.rs` 统一调用现有布局、主机筛选、保存等待，以及新增轻量交互、
目录兼容与 MCP 桥接检查。浏览器使用独立 profile 和随机本地调试端口。
退出后核验本次浏览器进程组；主进程退出仍有子进程时，回收本次进程组，
确认空组后再删除 profile。

真实 Rust fixture 使用 `./scripts/dev setup`、`start`、`status`、`stop`，
运行结束确认 `cleanup_confirmed=true`。
SDK、依赖锁和新增检查脚本要求完整自动门禁，不只运行 UI 测试。
独立 Chromium、系统 WebKit 探针和 fixture 通过，仍不代表日用 Magpie 容器已验收。

此分支保持版本 0.3.85，不安装或重载正式插件。
发布后需要重新打开看板才能加载新 HTML；数据刷新不会替换页面。
PWA 清单和离线页沿用中性色与系统浅深色，不缓存会话数据或 API 响应。
