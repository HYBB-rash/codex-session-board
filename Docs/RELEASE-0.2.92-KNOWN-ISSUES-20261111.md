## 发布与回滚

部署前核对旧进程身份，使用旧 0.2.82 二进制和旧配置停止旧服务。
停止后以 SQLite Backup 保存根库及全部远端子库，并核对完整性、会话 ID 与备注。
旧配置和原生分区保留；用既有迁移命令生成独立五状态配置，保持原数据目录、
本机 1800 秒定时归档、远程定时归档关闭及两台 Hermes 自动连接关闭。
失败时停止新服务，恢复已核验的数据库快照、旧配置及旧插件，再启动旧二进制。
整库恢复会覆盖上线后的新数据，因此回滚前须先另存 92 运行后的全部库及
`source.json`、`scan-progress.json` 和归档报告，再判断是否需要恢复旧快照。
82 不保留 92 的 `restoration_errors` 恢复队列字段，程序回退并非完全无损。
本地快照也不能撤销已经发生的原生改名、移动或归档，须按实际写入逐项核对。
部署实际结果及回执见本任务的最终 handoff；未执行的步骤不记作成功。
