# 远端性能门禁

连接复用由每个主机实例持有独立 SSH master、随机私有目录和 socket。
仍然逐次解析当前目标，核对来源记录，并在远端核对 UID、HOME 和 CODEX_HOME。
不写用户 SSH 配置，不与其他主机、实例或程序共用控制 socket。

观察连接在远端压缩完整轮次响应，保留每个用户输入 ID、所有答复 phase、
轮次状态和时间，不传输正文及工具输出。压缩程序随本地二进制携带并在连接时执行，
不在远端安装文件或服务。写入连接继续读取原始完整结果。

Codex 0.167.0 的内置 `itemsView=summary` 仅选择首个用户消息与最后一个助手消息，
会遗漏同轮追加输入，也可能遗漏较早的最终答复证据。因此不直接用它代替完整证据。
上游实现见 `codex-rs/app-server-protocol/src/protocol/turn_items_view.rs`。

## 每次测试必须通过

`cargo test --locked --offline` 和提交钩子固定执行以下检查，不依赖远端在线：

- 注入 500ms 建连成本，八次核验只允许一次认证；热核验中位数小于 200ms，
  同时小于冷核验的 40%。每次仍须实际核对 peer。
- master 失败、请求截止时间、锁等待、连接重建和进程回收必须正确。
- 保留同轮多个输入、最终答复、运行中、完成、失败和中断的证据。
- 约 3.75MB 的固定完整响应压缩到小于 600 字节且小于原来的 0.1%；
  九次压缩的中位数小于 80ms。
- 覆盖观察与归档连接的分工、WebSocket 分片、控制帧、二进制帧、
  扩展长度及错误帧，不能以损失正确性满足性能阈值。

测试失败应修复实现，不能放宽阈值、忽略失败或删除样本来通过。
这些检查可阻止重复认证、恢复传输正文和压缩处理变慢，不把公网抖动引入离线测试。

## 真实主机门禁

在已登记主机可达、现有 SSH 凭据可用时运行：

```zsh
cargo run --release --locked --offline --example remote_performance -- /path/to/config.json HOST_ID
```

配置读取主机登记和连接方式；所有看板数据库及登记副本建立在临时私有目录。
调用真实 SSH、Codex 代理、会话列表和轮次读取；通过真实状态保存入口进行二十次
保存并读回，但只修改隔离数据库，不改实际 Codex 会话的标题、内容或归档状态。
十二个结束轮次按交替顺序比较完整结果和压缩结果，必须逐项证据一致。

固定阈值为：状态保存中位数小于 200ms、p95 小于 350ms，
十二次摘要读取合计小于 250ms，摘要传输量小于完整结果的 10%。
失败输出 `passed=false` 并返回非零；连接失败、样本不足或证据不等也失败。
真实门禁需要可用主机与认证，单独运行，不能用离线门禁冒充真实远端验证。
不支持环境变量放宽门禁。报告包含每次样本，保留失败回执后再调查和修复。
