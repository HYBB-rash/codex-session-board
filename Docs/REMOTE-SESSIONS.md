# 远程会话接入

本分支将远程会话接入现有业务实例。部署和真实验收进度以
context/STATE.yaml、当前完整验收报告及专项报告为准。
旧 outputs/remote-sessions-20261107/ 只证明第一阶段的只读发现与本地备注，
不能用来签收新实现。

## 功能与边界

本机根实例管理每台远程主机的独立 App、Store 和连接，
共用原有状态推进、输入版本、人工选择、备注、标题队列、
原生位置校验和归档逻辑。远端不安装另一套看板，不公开 HTTP 端口。

| 功能 | 本地与远程的共同规则 |
| --- | --- |
| 运行阶段 | 实际开始、恢复、等待、中断和结束驱动状态；重复快照保留人工选择 |
| 备注与标题 | 使用相同版本检查和标题规则；失败保留持久队列并后台重试 |
| 原生分区 | 先读取目标主机的权威位置，拒绝过期修改，写后独立读回 |
| 归档 | 检查输入、状态和位置；定时归档仅在配置明确启用时运行 |
| 导航 | 使用原始 threadId 和 hostId 打开原会话，观察器不发送消息或代批任务 |
| 项目 | 主机参与项目和卡片身份；远程路径不在本机解析或检查 Git |
| 断线 | 保留缓存和已有内容；需要权威核验的操作明确失败，不显示成功 |

旧 `auto_archive_seconds` 仍只控制本机；远程定时归档另由
`remote_auto_archive_seconds` 显式启用，默认关闭，不扩大既有自动归档范围。

远程空会话针对已登记的远程项目：直接创建无输入的持久会话，
随后通过客户端登记项目并验证 host、项目、cwd 和工作区根。
请求先持久登记，丢回执不会自动重复 thread/start。
未确认结果保持 pending；恢复或释放前需要实际核对客户端。
此功能不创建项目，不启动模型回合。

## 连接、身份与缓存

主机来自当前客户端登记，默认尊重自动连接偏好。
关闭自动连接的主机可在看板明确连接，或调用 board_connect；
该选择仅作用于本次服务运行，不修改客户端偏好。
不因枚举历史而隐式连接未启用的主机。

每个目标通过 OpenSSH 连接现有 canonical app-server proxy。
登录环境、启动标记、Peer 信息、WebSocket 握手均有边界和总时限；
代理关闭时清理看板拥有的进程组，不停止用户 daemon。
远端需要 Python 3、可用的 codex app-server proxy 和正常 SSH 身份认证。
代理、时钟及实际 initialize 必须指向同一数据来源。

source.json 的版本 2 记录 hostId、有效 SSH 主机/用户/端口、
远端 UID、物理 HOME、物理与声明的 CODEX_HOME。
alias 改目标、用户或数据目录改变、记录损坏或旧数据缺少身份记录时，
保留数据并拒绝写入，不删除记录后自动接管旧库。
同时登记到同一可观测用户和数据目录的多个主机拒绝写入；
移除重复登记后可恢复，不把同 UUID 的不同主机合并。

远程数据库位于 data_dir/remote-hosts/ 下按完整 hostId 哈希分隔。
沿用本地 Store 模式；旧根库 remote_sessions/remote_projects 保留分类资料，
人工内容只导入一次。较新的子库备注、标题和已归档墓碑优先，
不会被旧根缓存复活或覆盖。
已移除或禁用主机的持久缓存仍可读取；单个损坏库不会吞掉其他主机。
分页进度持久化，重复游标、缺页和部分失败不能被报告为完整扫描。

迁移枚举磁盘上的全部持久主机，不仅迁移当前启用项。
每个 SQLite 库使用在线备份，包含已提交 WAL；
只附带 source.json 与 scan-progress.json，不复制运行锁、socket 或进程记录。
目标冲突拒绝覆盖；失败按本次创建的 inode 回滚，保留外部新增或替换项。
合法授权根和配置父目录别名可用，根内数据库及侧车链接仍拒绝。

## 维护与可靠性

远程接入增加的是传输、来源核验、校时、连接生命周期和持久缓存，
业务规则仍由一套实现维护。不同主机不共用前台操作锁，
停用连接先阻止新操作，再等待该实例的旧操作结束。
运行时间以有往返时限的采样转换到本机时间域；异常采样拒绝，
不能把不可验证的时钟当作有效阶段。

仍有明确的维护边界：

- 客户端内部项目、分区和桥接格式可能随升级变化，需要版本回归。
- 上游没有原子位置 CAS；读后写间的外部竞争和位置 ABA 不能完全消除。
- 相同可观测身份的物理克隆或同路径替换不等同于可靠的机器身份。
- daemon 未报告、且两次观察之间已结束的极短阶段不能凭空还原。
- 数据迁移是逐库快照，不是跨库统一事务；进程被杀或掉电后的残留需审阅。
- daemon 返回的 CODEX_HOME 若不能与物理 Peer 路径核对，保持拒写；
  不通过猜测或扩大匹配范围来声称来源一致。

正式签收必须同时完成冻结 31 条完整验收和
scripts/verify_remote_release.py 的原生五状态与远程专项，
使用同一最终源码和 executable，审阅真实日志、GUI 和白名单写入审计。
只通过自动测试、实验报告或旧安装版本均不算完成。
