# 远程新建设置

在看板打开「远程连接设置」，输入主机名或 IPv4 地址、SSH 用户、端口和项目绝对路径。首版使用直连 OpenSSH 和已有的密钥或 Agent。远端主机密钥须已受信任，目标用户运行的 Codex 后台须能返回唯一的单目录项目。通常会核对账号身份。远端明确以无需 OpenAI 认证的本地提供方运行时，核对 SSH 目标、远端运行目录和项目。包含跳板、动态 `Match` 或外部 `Include` 的 SSH 配置需要在 Codex 侧栏管理。

## 授权与重用

- 同一目标已有 Codex 连接时从原连接进入。无别名的旧连接在 Codex 侧栏打开原项目。看板保留已有登记及其会话。
- 已有可用的 OpenSSH 别名时优先复用。多个别名符合时先选择一个，预览前核对该别名和目标身份。只有缺少可用别名时才预览新别名。
- 预览列出 SSH 文件和 Codex 登记改动。选择「拒绝」会在看板保存对该主机、SSH 用户及端口的决定。通过「重新启用」可再看一次预览，仍需点击「同意并配置」才会写文件并请求打开客户端。
- 已有别名若需要开启自动连接、登记目录或导入旧项目，也会提示确认。已有连接、自动连接和目录条件均满足时可以直接请求打开原生输入页。

## 恢复和项目归属

SSH 改动集中在 `~/.ssh/codex-session-board.conf` 的独立 `Host` 段。必要时在 `~/.ssh/config` 顶部加入对应 `Include` 和作用域重置。设置中可继续已同意的配置；看板先核对文件、远端身份和客户端现有登记，可沿用同一别名续做。若文件被编辑、同名连接不一致，或客户端自动连接已被明确关闭，需核对后重新预览。

取消该设置时，先在 Codex 侧栏确认改动所涉及的连接和目录，再移除本次生成的登记。仅从看板管理的文件中移除本次生成的 `Host` 段。若无其他别名使用该文件，可移除本次新增的 `Include` 和紧随其后的 `Host *`。保留原有的 SSH 别名、手工改动和其他连接。

在原生输入页核对主机和目录，发送第一句话后回到看板刷新。项目告警表示远端会话的项目归属仍需确认。可从同一张卡片核对会话 ID、目标主机和目录，确认已有项目归属后读回结果。
