# 会话看板的管理范围

## 决定

2026 年 11 月 21 日确认，**网页 Chat 和桌面云端 Work 均不纳入 Codex 会话看板的管理范围**。这两类会话继续由 ChatGPT 原应用管理。

现有 Codex 会话和原路径能发现的旧本地 Work 继续由看板管理。Work 能调用本机工具或读取本机文件，不能据此将会话归为旧本地 Work，会话归类以其来源和标识为准。

## 理由

独立试版曾验证两条专用会话的改名、归档和恢复可以写回。接入依赖随桌面版本变化的内部接口，网页历史缺少可独立核对的完整清单，源端写入的身份绑定与实际桌面发送处的停用保证也缺少验收证据。

## 影响

不采用默认关闭的可选 ChatGPT 来源方案。看板不导入或检索这两类云端会话，不为它们生成卡片、保存备注或写回改名和归档。独立试验保留为调研记录，现有 Codex 路径继续使用。
