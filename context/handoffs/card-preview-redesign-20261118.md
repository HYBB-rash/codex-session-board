# 卡片预览原型交接

2026-11-18。以 GitHub main 的 `464221b` 为基线。PR #24 和 v0.4.7 属于此前的「本轮最终答复」交付。本次改版的产品契约以当前委派书为准。

| 场景 | 0.4.7 行为 | 原型行为 |
| --- | --- | --- |
| A 读取中点 B | 模态阅读器挡住 B。现有身份对象只保护面板关闭后的迟到结果 | 一次点击切换。清空旧正文，按选择实例忽略任何过期结果 |
| 读上一条时新回复完成 | 运行中没有入口。轮次变化或连接异常时面板关闭 | 状态栏提示「查看新答复」，保留正在阅读的正文及其滚动位置 |
| 拖标题、点卡内操作 | 使用拖动结束后的防误触保护。卡片背景点击排除内嵌控件 | 沿用拖动与点击的区分。卡内调整保持原操作 |
| 面板打开后点卡、空白或正文 | 卡片不可直接切换。关闭按钮与 Esc 可退出 | 卡片切换，空白关闭，正文可选中和独立滚动。Esc 回到当前卡片 |
| 空答复、读失败、Markdown | 空答复隐藏按钮，读失败关闭面板，正文按纯文本显示 | 空答复和失败分别提示，保留进入原会话。用带表格、代码块等格式的示例正文对照 |
