# 项目下拉与搜索切换

日期：2026-11-06，Asia/Shanghai；沿用 codex/pwa-support 分支。
本轮实现用户已确认方案，并沿用同一会话的分批提交授权。

## 行为

顶部项目下拉包含全部项目、默认工作区与当前本机加载项目，旁边按钮切到全局
标题、路径搜索。模式各自保留当前值，导航与列计数使用筛选结果。
移除项目时会话归默认，重新添加同目录时自动识别，状态、备注与版本不改变。
选中项目被移除时切默认并提示，重新添加后页面保持当前选择。

采用只读本地完整登记表，避免原生 list_projects 丢失 Git 探测失败项目或其他根目录。
登记表损坏保留旧快照；歧义或 Git 读取异常显示待确认，不把未知归属冒充默认。
支持目录组件、最长嵌套根、符号链接、多个根与 Git 共享目录的工作树识别。
本机路由器项目的 .git 缺少 HEAD，现场验证发现它会干扰其他工作树；
已将无关残缺仓库隔离，并增加回归。两名只读代理参与来源与前端检查。
