# 原生模拟连接断开回归

0.3.24 的 Mac 云端完整成功，Mac 完成升级、回退及再升级。
Linux 云端前台耗时为 448–454ms，原 1000ms 断言通过，但模拟服务器向已断开的客户端
写帧长度时发生 Broken pipe，连接线程错误在测试收尾被再次抛出。

新回归先确定性复现相同 Broken pipe；处理仅限连接已终止的 I/O 错误，结束该连接。
其他 I/O 和协议错误继续传播。另一个回归明确要求写端半关闭后的畸形 JSON 仍返回协议错误。
回复合并为一个完整帧写入，业务断言、原时间上限、冻结需求、模型和锁均不变。
Mac 回归进一步确定性复现已关闭对端令设置读取超时返回 EINVAL；peer_addr 同时报告已断开，
对端未关闭时两项均成功。仅该平台上这两项同时确认断开时正常结束连接，其他错误仍传播。
三条回归登记在 DELIVERY-001，自动项增至 564。原始失败、最小实验及红绿回归记录保留。
