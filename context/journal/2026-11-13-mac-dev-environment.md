# 2026-11-13 Mac 隔离开发环境

在独立 `codex/mac-dev-environment-20261113` 工作树实现开发入口，
避开原 main 的热日志恢复和正式部署任务。Mac 两份任务各有工作树、target、
私有配置、数据库、HOME、桌面/侧栏 socket 和生命周期控制。

复用真实 Rust 看板与公开原生 RPC，只替换外部依赖；导航仅记录。
进程组由存活守护者持有，停止确认无存活后代；身份与健康读取固定同一 TCP 连接。
本机验证环境误配拒绝、端口竞争重试、畸形控制消息、依赖冻结和强制收尾。
Mac 验证真实浏览器拖拽、独立备注、刷新、导航、停止 A 时 B 写入、
重启持久性、fixture 崩溃隔离及幂等操作。最终源码再跑同一流程并保留外部报告。

Mac 临时目录别名、接收 socket 非阻塞继承和 Chrome 退出时序失败均保留取证并修正。
Mac 正式 0.3.38 在双任务通过窗口保持相同 PID 与配置/安装/缓存摘要。
两端正式版本由另一个交付任务更新，本任务未推送、安装或重载。
Linux 正式 HTTP 在本机测试前后均未连接，保留独立待核验项。
完整业务仍以 31 条最终验收报告为准，缺少真实环境证据保持待验证。
