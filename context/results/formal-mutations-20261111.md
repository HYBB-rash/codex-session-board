# 原生模型与连续验证的变异检查

日期：2026-11-11，Asia/Shanghai。
基点：19c713d；版本/归档连续检查取自本任务工作区的待提交代码。

在临时编译单元中使用项目真实 Store 源码，每次只改变一个生产行为。
业务模型、测试断言及真实工作区文件不变。编译成功后运行指定测试；
只有实际运行且因目标断言失败才记为捕获，编译失败不计入。
原实现的路径检查、版本与归档检查均通过。

| 临时改变 | 实际捕获点 |
| --- | --- |
| 删除读回待归档位置时的输入保护 | 连续路径的 review 标记不一致 |
| 禁用 pending 同轮识别 | Retry 后列与模型不一致 |
| 禁用已确认完整阶段去重 | 重复快照被当作新阶段 |
| 重复草稿返回 fresh=true | 首次/重复创建标志错误 |
| 原生版本每次写成 1 | 第二次位置变化未得到版本 2 |
| 新输入不增加版本 | 首次输入仍为输入版本 0 |
| 每次观察都增加输入版本 | 重复快照错误增加输入版本 |
| 删除编辑的状态版本保护 | 旧状态版本返回成功 |
| 删除编辑的输入版本保护 | 旧输入版本返回成功 |
| 删除归档的状态版本保护 | 旧状态版本返回成功 |
| 删除归档的输入版本保护 | 已重新确认后的旧输入版本返回成功 |
| 归档准备返回空输入依据 | 返回值与实际输入快照不一致 |
| 归档确认不执行自身校验 | 非待归档列被允许归档 |
| 编辑校验拒绝前删除标题队列 | 拒绝后的完整数据库快照改变 |

共 14 个单点变异被捕获。这是上述回归保护的证据，不是对所有可能变异、
所有网络/并发/进程崩溃行为的证明。后续真实磁盘重启和时间边界另行记录。
