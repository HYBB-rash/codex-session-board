# T3 · 四列告警回归结果

四列告警沿用原测试 ID。观察器读取临时会话的完整轮次，再从 `App::snapshot()` 读回告警、卡片身份、人工列和备注。旧测试对 `EvidenceGaps::record` 返回计数的断言已经删除。生产代码只把传入本轮的单调时间交给告警计时，正常轮询仍通过 `Instant::now()` 取时。

| 观察时间（秒） | 轮次证据 | 快照告警 |
| --- | --- | --- |
| 0、29、30 | 发过输入，活跃状态与历史完成记录冲突 | 无、无、有 |
| 31 | 已结束的旧轮次有可靠终止时间 | 清除 |
| 60、89、90 | 同一会话重新缺证 | 无、无、有 |
| 91 | 再次读到可靠证据 | 清除 |
| 120、150 | 只有这两次完整观察 | 无、有 |

十次快照均读到人工待归档和原备注。在 C1 基线上，保留旧告警时钟时新测试在第 30 秒失败；恢复后遗漏重置会在第 60 秒误报；把最少观察次数提高到三次会在第 150 秒漏报。三次分别退出 101。临时把计数器换成记录首次观察时间的表，分别处理首次和后续观察，十步全部通过。已撤销这些实验改动。

源码外实验目录为 `~/.local/share/codex-session-board/integration/t3-four-column-warnings-20261121/`。`original-clock.log`、`forgot-recovery.log`、`three-observations.log` 保留原始失败，`equivalent-first-seen.log` 与同名补丁记录等价实现。需求授权与完整 ID 见[任务卡](../tasks/active/t3-four-column-warnings-20261121.md)。Linux 使用受控 RPC 和正式快照，真实宿主尚未现场验证。
