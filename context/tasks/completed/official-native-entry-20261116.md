## 实现

开发及验证头：7bf9cbf；基础：26ba9f4；版本清单保持 0.3.90。

- 删除客户端 archive/应用副本准备工具、专用 new-remote 路由和能力清单依赖。
  老 native_new_capability 配置兼容忽略，不再要求修改客户端。
- 原生入口每次重新读取 SSH alias 与单目录，拒绝缺失/重复 alias、
  已移除主机、多目录及不安全路径。目标主机实时目录项目接入同一导航入口。
- 只交给原装客户端打开原生输入页，用户首次发送后才产生持久会话；
  无 UUID 猜测、空会话账本、后台 thread/start 或自动首条输入。
- 新会话后台项目归属为空时，在实际卡片点击“归入项目”。
  验证同主机、账号、UUID、原生来源、首条用户输入、cwd 与项目 roots，
  经 App::connection 的窄权限 ProjectWriter 写入，再独立读回同一 UUID。
  已有其他项目不覆盖，已归入目标只读回，失败不重建。
- 提交中禁用操作、拦截 Esc；失败保留同一会话供重试。

使用顺序：选主机/目录 → 原生页面核对后发送 → 返回看板刷新。
若仍在原项目筛选中，可切换“全部项目”找到实际新会话，再确认归属。
旧连接没有 alias 时需在 Codex 中登记并统一复用 SSH 别名；
同一实际远端的重复登记仍受既有来源保护限制，本次不删除或迁移用户登记。
