# TypeScript 会话看板验收

上游行为基线为 `2cc4e6bb4e03d7cfabce0733a91a328004a9f3fc`。Fedora 44 的 Enhancer 副本通过本机和远程原生移卡检查点。macOS arm64 的目标 Codex 构建在加载看板之前拒绝了经过修改的启动归档，因此发布条件未满足。

## Fedora 44 实测

宿主是 Codex `26.1111.71704`。远程测试使用同一窗口已经连接的 `remote-ssh-discovered:macbook`。涉及会话写入的操作只使用本轮创建的专用卡。

| 操作 | 实测结果 |
| --- | --- |
| 本机及远程原生拖放 | 两张专用卡从待审阅拖到进行中，原生侧栏显示变化，目标主机读回新分区。从原生侧栏移回后，旧表单被拒绝，已保存的备注保留。见[移卡检查点](session-board-native-checkpoint.md)。 |
| 发现和预览 | 已连接主机返回 9 个远程项目。两端读回的最新完整回复分别为 `01a2030f-d1d1-78c2-b969-9ae91b6fd013` 和 `01a2030f-d1ea-78b0-b061-713742857e5c`，均核对了专用回复标记。 |
| 观察器 | 关闭看板后，在远程专用会话发起新一轮请求。看板读回「进行中」及「待审阅」，最终答复轮次为 `01a20335-5bc9-7c72-ba75-5f8f38082e1a`。标题最终同步，备注保留。首轮实测发现输入条目分两次到达时重复增加输入版本，随后实现改为仅在获取用户项后建立输入键。 |
| 手动归档和重读 | 本机批次 `4ac26c51-d1b3-494e-9c29-431ae248c999` 由 `awaiting` 到 `archived`。重启后卡片和批次仍可重读，备注保留。进入归档记录时，原生页面定位到相同 UUID 和 `hostId=local`。 |
| 远程定时归档 | 临时配置远程间隔为 12 秒且保留专用会话写入限制。关闭看板后将远程专用卡置于待归档，后台批次读回归档且备注保留。结束后恢复测试配置。 |
| 项目新建入口 | 远程目录可读。未在桌面登记的目录通过同一窗口打开了原生项目对话框，显示原远程主机。验收选择取消。远程项目从确认登记、打开空白输入页到实际生成会话和回读归属仍待验证。 |
| 网页和 PWA | 隔离 Chrome `158.0.8127.36` 加载实际看板，Service Worker 获得控制，Chrome 报告无可安装性错误。系统安装和独立窗口启动仍待签收。 |

重复查看、预览和定时归档复验命令见 [`acceptance/fedora-tail.mjs`](../acceptance/fedora-tail.mjs)。其中归档模式只适用于尚未归档的指定专用夹具。PWA 可安装性检测见 [`acceptance/verify-pwa.mjs`](../acceptance/verify-pwa.mjs)。

## 安装、更新和回退

Fedora 安装版从实际网页看板点击「更新」。交付候选已通过 `0.3.2 → 0.3.3 → 0.3.2`，更新和回退均在重启后读回对应版本。隔离数据夹具的 SHA-256 保持一致，卸载恢复了副本的原始启动归档。原始记录位于 `state/acceptance/fedora-installed-0.3.3.txt`。

MacBook Pro 上的 macOS arm64 和 Codex `26.1111.21308` 已单独取证。实际安装检查发现 `Codex Framework` 内嵌 ASAR 完整性字典摘要。隔离副本的签名检查通过后，桌面启动仍因完整性摘要拒绝。安装器现在会在复制之前报告该条件。Mac 上实测归档校验、解压、版本选中和回退，尚未运行看板。记录位于 `state/delivery/macos-actual-host.txt` 和 `state/delivery/macos-isolated-launch-and-restore.txt`。

## 自动对照与验收门槛

- 冻结的 31 条需求及独立模型以 SHA-256 校验。正式 TypeScript 服务在隔离磁盘夹具中重放 520 条状态转换及 1,417 次操作，其中 40 次重开和 40 次查看均未产生持久写入。
- 35 项自动化测试覆盖 18 个 HTTP 和 MCP 操作的路由对照、7 条 CLI 命令、归档校验及回退、账号和主机分离、旧 SQLite 主库和远程分库、已提交 WAL、失败与重试。
- `0.3.3` 的两个归档均从当前构建生成，SHA-256 校验通过。包内含安装说明、签收用版本清单、MCP 资源与运行时，没有运行目录、日志、测试文件及 `node_modules`。
- [逐项清单](../acceptance/candidate-map.json)保留未验断言。尚需独立验证同 ID 跨主机的真实写入、远程完整新建、实际 MCP App 渲染、系统 PWA 安装、macOS 宿主运行和已安装看板更新后的全功能复验。冻结模型通过只解除其覆盖的自动检查。
